# 📊 Vrinda Store Sales Analysis

## 📌 Project Overview

This project performs an end-to-end **Sales Analysis** of Vrinda Store using Microsoft Excel. The analysis transforms raw transaction data into actionable business insights covering sales performance, customer behavior, product trends, and channel effectiveness.

---

## 🎯 Business Objective

Analyze sales data to answer key business questions and provide data-driven recommendations for improving store performance.

## 📊 Dataset Overview

The dataset contains e-commerce sales transaction information including:

- Order ID, Customer ID
- Gender, Age
- Order Date, Order Status
- Channel, SKU, Category, Size
- Quantity, Amount
- Shipping City, Shipping State
- B2B Information

---

## ❓ Business Questions & Answers

| # | Question | Answer |
|---|----------|--------|
| 1 | What is the overall sales performance? | Analyzed revenue, order quantity, and transactions across dimensions |
| 2 | Which customer segments contribute most to sales? | Analyzed by **gender and age groups** to identify top contributors |
| 3 | Which product categories perform best? | Compared categories by **sales amount and quantity** |
| 4 | Which sales channels generate the most sales? | Analyzed across different **sales channels** |
| 5 | Which states contribute the most sales? | **State-level analysis** to identify top regions |
| 6 | How does sales performance change over time? | **Monthly trends** to identify demand patterns |
| 7 | What is the distribution of order statuses? | Delivered, Cancelled, Returned, and other statuses |

## 📈 Analysis Performed

| Category | Analysis |
